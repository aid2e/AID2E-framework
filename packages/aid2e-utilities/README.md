# aid2e-utilities

Utilities for AID2E Framework including configuration management and ePIC-specific tools.

## Installation

```bash
pip install -e .
```

For development:

```bash
pip install -e ".[dev,docs]"
```

## Features

### Configurations

Generic configuration utilities for AID2E workflows.

### ePIC Utils

ePIC-specific utilities and configuration tools.
